# Masks Off: voice lines to record

Voice: ElevenLabs "John Doe - Gravelly Storyteller" (from the Deep voices list).

Generate each line below as an MP3 and save it with the exact file name shown. Upload all the files into the `public/voice` folder of the GitHub repo (the app plays any file it finds and uses the phone's own voice for any it does not).

Tip: in ElevenLabs set Stability fairly high (about 60-75%) and speed slightly slow (about 0.85-0.9), keep the settings identical for every line, and keep the "..." at the end of a line so the voice trails off.
